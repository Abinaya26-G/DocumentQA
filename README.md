# DocumentQA

An AI-powered web application for uploading PDF documents and asking questions based on their content.

Built with React, Spring Boot, Spring AI, Google Gemini, and Apache PDFBox.

**Live Demo:** [https://documentqa-j8ny.onrender.com](https://documentqa-j8ny.onrender.com)

**GitHub:** [https://github.com/Abinaya26-G/DocumentQA](https://github.com/Abinaya26-G/DocumentQA)

## Features

* Upload and process PDF documents
* Ask questions using natural language
* Get AI-generated answers based on document content
* PDF text extraction using Apache PDFBox
* REST API built with Spring Boot
* Dockerized backend
* Deployed on Render

## Tech Stack

**Frontend:** React, Vite, JavaScript, CSS
**Backend:** Java 21, Spring Boot, Spring AI
**AI:** Google Gemini
**PDF Processing:** Apache PDFBox
**Deployment:** Docker, Render
**Version Control:** Git, GitHub

## Running Locally

Clone the repository and configure your `GEMINI_API_KEY` environment variable.

Then run the backend with:
`mvn spring-boot:run`

Run the frontend with:
`npm install`
`npm run dev`

The backend runs on port `9090`.
